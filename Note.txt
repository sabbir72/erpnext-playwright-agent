Discovery Agent-এর কাজ হলো ERPNext system পড়ে AI-এর জন্য structured knowledge তৈরি করা।

Discovery কোনো business test result তৈরি করবে না এবং existing business record open/save করবে না।

3. DocType Naming Rule

সবসময় Main DocType এবং Search Name আলাদা থাকবে।

Main DocType     = Contract
Global Search    = New Contract
UI Action        = New
Stored filename  = 000X_contract.json

JSON example:

{
  "doctype": "Contract",
  "document_name": "Contract",
  "search_name": "New Contract",
  "action": "New"
}

New কখনো main doctype বা filename-এর অংশ হবে না।

4. Module Card Parsing Rule

ERPNext shortcut widget-এ এমন structure থাকতে পারে:

<div class="widget shortcut-widget-box" aria-label="Lead">
    <div class="widget-title">
        <span class="ellipsis" title="Lead">Lead</span>
    </div>
    <div class="indicator-pill">0 Open</div>
</div>

এখানে:

DocType       = Lead
Counter       = 0 Open
Global Search = New Lead

0 Open, 15 Assigned, 20 Open ইত্যাদি কখনো DocType name হিসেবে search করা যাবে না।

13. Failure Interpretation

No discovery JSON found

Discovery output folder-এ JSON নেই বা ভুল project directory থেকে command চালানো হয়েছে।

Check:

pwd
ls data/discovery

validation status is FAILED

Normalize এখনই চলবে না। আগে Validation কেন failed হয়েছে সেটা ঠিক করতে হবে।

Global search box not found

ERPNext Home-এর search selector verify করতে হবে।

Search result not found

Search term হওয়ার কথা:

New <Main DocType>

উদাহরণ:

New Lead
New Contract
New Purchase Order

0 Open / Assigned search হচ্ছে

Module widget title parsing ঠিক হয়নি। আগে .widget-title span[title] / aria-label থেকে আসল DocType নিতে হবে।

16. Final Working Principle

সবচেয়ে গুরুত্বপূর্ণ তিনটি rule মনে রাখতে হবে:

1. Module card থেকে শুধু আসল DocType title নিতে হবে.
2. Search করার সময় New + DocType ব্যবহার করতে হবে.
3. JSON record করার সময় main DocType থেকে New বাদ রাখতে হবে.

Example:

UI Card       = Lead + 0 Open
Main DocType  = Lead
Global Search = New Lead
UI Action     = New
JSON          = Lead
